# kNN и оценка моделей

Нормализация, Pipeline, кросс-валидация и классификация текстов методом ближайших соседей.

| Файл | Назначение |
| --- | --- |
| [knn_pipeline.ipynb](knn_pipeline.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [knn_text_classification.ipynb](knn_text_classification.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [cross_val.py](cross_val.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Для загрузки дополнительных моделей и ресурсов установите `ALLOW_DOWNLOADS = True` в первой ячейке ноутбука. Загрузчики датасетов могут обращаться к сети при отсутствии локального кеша.
