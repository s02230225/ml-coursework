# Линейные модели

Регрессия, регуляризация Ridge/Lasso, классификация и визуализация разделяющих поверхностей.

| Файл | Назначение |
| --- | --- |
| [classification.ipynb](classification.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [regression.ipynb](regression.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [regularization.ipynb](regularization.ipynb) | Ноутбук с постановкой, реализацией и анализом |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Загрузчики датасетов могут обращаться к сети при отсутствии локального кеша.
