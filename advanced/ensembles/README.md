# Ансамбли

Bagging, Voting, Stacking, собственный BlendingClassifier и регрессия по изображениям потенциала.

| Файл | Назначение |
| --- | --- |
| [ensembles.ipynb](ensembles.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [potential_prediction.py](potential_prediction.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
