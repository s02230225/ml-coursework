# Метод опорных векторов

Линейные и нелинейные SVM, ядра, дисбаланс классов и калибровка вероятностей.

| Файл | Назначение |
| --- | --- |
| [svm_base.ipynb](svm_base.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [svm_research.ipynb](svm_research.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [svm_solution.py](svm_solution.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Для загрузки дополнительных моделей и ресурсов установите `ALLOW_DOWNLOADS = True` в первой ячейке ноутбука.
