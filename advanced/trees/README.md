# Деревья решений

Обучение дерева регрессии, подбор глубины, визуализация и важность признаков; критерии Джини, энтропия и ошибка классификации.

| Файл | Назначение |
| --- | --- |
| [decision_tree.ipynb](decision_tree.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [split_measures.py](split_measures.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Загрузчики датасетов могут обращаться к сети при отсутствии локального кеша.
