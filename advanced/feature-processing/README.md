# Обработка признаков

Очистка табличных данных, масштабирование, OneHotEncoder и подготовка признаков для регрессии.

| Файл | Назначение |
| --- | --- |
| [feature_processing.ipynb](feature_processing.ipynb) | Ноутбук с постановкой, реализацией и анализом |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Для загрузки дополнительных моделей и ресурсов установите `ALLOW_DOWNLOADS = True` в первой ячейке ноутбука.
