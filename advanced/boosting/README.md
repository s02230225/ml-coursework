# Градиентный бустинг

Сравнение GradientBoosting, CatBoost, XGBoost и LightGBM; настройка параметров и прогноз числа наград по признакам фильмов.

| Файл | Назначение |
| --- | --- |
| [boosting_comparison.ipynb](boosting_comparison.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [boosting_tuning.ipynb](boosting_tuning.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [awards_prediction.py](awards_prediction.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
