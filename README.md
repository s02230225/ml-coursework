# Практикум по машинному обучению

**Python · NumPy · pandas · scikit-learn**

Ноутбуки по работе с массивами и таблицами, масштабированию, kNN, линейной регрессии, классификации и статистическим признакам. Подборка показывает переход от вычислительных операций к обучению и оценке моделей.

Материалы открываются в Jupyter. Запускай ячейки выбранной работы последовательно после подготовки её набора данных. Зависимости определяются первыми ячейками и импортами конкретного ноутбука.

Выводы ноутбуков очищены, чтобы файл удобно просматривать и сравнивать. Данные и результаты эксперимента формируются при локальном запуске. Внешние корпуса и большие артефакты в репозиторий не входят.

Для небольших автономных реализаций нормализации, категориальных признаков и кросс-валидации см. [ml-preprocessing](https://github.com/s02230225/ml-preprocessing). Подборка имеет учебное назначение; названия [Base]/[Research] отражают структуру заданий курса.
